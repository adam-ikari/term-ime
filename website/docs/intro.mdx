# term-ime

**SSH 上，终于能打中文了**——在 Linux TTY / TUI 里直接打中文的虚拟终端，不装 X、不装 Wayland、不碰 D-Bus，同时是**输入法引擎库**与**TUI 输入法组件**：

- **输入法库（term-ime-lib）**：封装 librime 的 `ImeEngine` 接口，任何程序可嵌入获得中文拼音输入（见 [输入法库](/docs/library)）
- **TUI 输入法组件（term-terminal）**：候选栏、状态栏、设置面板，可复用的终端输入界面（见 [TUI 输入法组件](/docs/tui-component)）

不依赖桌面环境、图形 IME 框架或额外运行时——单文件静态二进制，拷贝即用。

## 为谁

- TTY 常驻用户、服务器运维
- 极简桌面、无 GUI 的嵌入式 / 修复环境
- 任何「没有桌面输入法,但又想打中文」的终端
- 想在自研 TUI / 编辑器 / 终端模拟器里嵌入中文输入的开发者

## 核心特性

- **PTY 虚拟终端 + VT/ANSI 解析**:完整支持 SGR 颜色(16 色、256 色、24bit 真彩),前景/背景/加亮/反显;ED/EL 擦除(清屏、清行各 mode)
- **librime 拼音 + 模糊音**:简体中文;模糊音分 5 类——平翘舌(zh/z)、n/l、r 系、h/f、前后鼻音,每一类可在设置面板和配置文件里**单独开关**(默认全开,全关即精确拼音)
- **自适应候选栏 + 状态栏**:按终端宽度换行;方向键 / `PgUp` / `PgDn` / `,` `.` 翻页
- **可嵌入**:IME 引擎与 TUI 组件分层为独立静态库(`term-ime-lib` / `term-terminal`),可嵌入第三方 TUI 程序
- **设置面板**:`Ctrl+A S` 打开;可调界面语言(zh-CN / en)、候选词数量,以及各类模糊音开关
- **完全静态单文件,零运行时依赖**
