# term-ime

在 Linux TTY 里直接打中文的虚拟终端。内置拼音输入法,不依赖桌面环境、图形 IME 框架或额外运行时——单文件静态二进制,拷贝即用。

## 为谁

- TTY 常驻用户、服务器运维
- 极简桌面、无 GUI 的嵌入式 / 修复环境
- 任何「没有桌面输入法,但又想打中文」的终端

## 核心特性

- **PTY 虚拟终端 + VT/ANSI 解析**:完整支持 SGR 颜色(16 色、256 色、24bit 真彩),前景/背景/加亮/反显;ED/EL 擦除(清屏、清行各 mode)
- **librime 拼音**:简体中文,模糊音可开关(n/l、zh/z、r/l、r/y、hu/f、en-eng、an-ang)
- **自适应候选栏 + 状态栏**:按终端宽度换行;方向键 / `PgUp` / `PgDn` / `,` `.` 翻页
- **设置面板**:`Ctrl+A S` 打开;可调界面语言(zh-CN / en)、候选词数量、模糊音
- **完全静态单文件,零运行时依赖**
