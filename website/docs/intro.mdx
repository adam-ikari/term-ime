# term-ime：Linux TTY 终端输入法

在 Linux TTY / TUI 里直接打中文，不装 X、不装 Wayland、不碰 D-Bus。它同时是两个东西：

- 输入法库 `term-ime-lib`：封装 librime 的 `ImeEngine` 接口，任何程序都能嵌进来获得中文拼音输入（见 [输入法库](/docs/library)）
- TUI 输入法组件 `term-terminal`：候选栏、状态栏、设置面板（见 [TUI 输入法组件](/docs/tui-component)）

不需要桌面环境、图形 IME 框架或额外运行时。单文件静态二进制，拷过去就能跑。

## 适用场景

- 常年待在 TTY 里的服务器运维
- 没装桌面的最小化安装、嵌入式或修复环境
- 任何「没有桌面输入法，但想打中文」的终端
- 想给自己的 TUI / 编辑器 / 终端模拟器加中文输入的开发者

## 主要能力

- **PTY 虚拟终端 + VT/ANSI 解析**：SGR 颜色（16 色、256 色、24bit 真彩），前景/背景/加亮/反显；ED/EL 擦除（清屏、清行各 mode）
- **librime 拼音 + 模糊音**：简体中文；模糊音分 5 类，平翘舌（zh/z）、n/l、r 系、h/f、前后鼻音，每一类可在设置面板和配置文件里单独开关（默认全开，全关即精确拼音）
- **自适应候选栏 + 状态栏**：按终端宽度换行；方向键 / `PgUp` / `PgDn` / `,` `.` 翻页
- **可嵌入**：IME 引擎和 TUI 组件分成两个独立静态库（`term-ime-lib` / `term-terminal`），可嵌进第三方 TUI 程序
- **设置面板**：`Ctrl+A S` 打开，调界面语言（zh-CN / en）、候选词数量，以及各类模糊音开关
- **静态单文件，零运行时依赖**
