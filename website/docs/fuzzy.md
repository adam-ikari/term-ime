# 模糊音

模糊音让你可以用「不标准的读音」打出目标字词——方言、口音或个人习惯导致的平翘舌不分、前后鼻音不分等，都能被识别。term-ime 的模糊音**按组独立开关**，想开哪组开哪组。

## 五组开关

| 开关 | 覆盖 | 示例 |
|------|------|------|
| **平翘舌（zh/z）** | `zh/ch/sh` ↔ `z/c/s` | 输 `zi` 可出「知/之」 |
| **n/l** | `n` ↔ `l` | 输 `la` 可出「那/拿」 |
| **r 系** | `r` → `l`、`r` → `y` | 输 `lai` 可出「来/赖」 |
| **h/f** | `hu` ↔ `f` | 输 `fu` 可出「胡/湖」 |
| **前后鼻音** | `en/eng`、`in/ing`、`an/ang`（含 `ian/iang`、`uan/uang`、`üan/üang`） | 输 `zan` 可出「脏/葬」 |

默认全部**开启**（与历史行为一致），全部关闭即为精确拼音。

## 打开设置

按 `^A` + `S` 打开设置面板，用 `↑`/`↓` 移动到对应模糊音行，`←`/`→` 或 `Enter` 切换：

```
模糊音 平翘舌: [开] < 1/2
模糊音 n/l:    [开] < 1/2
模糊音 r 系:   [开] < 1/2
模糊音 h/f:    [开] < 1/2
模糊音 前后鼻音:[开] < 1/2
```

改动即时生效，无需重启。

## 示例

| 开启组 | 输入 | 候选（节选） |
|--------|------|--------------|
| n/l | `la` | 那、拿、哪、拉、啦 |
| 前后鼻音 | `fan` | 方、放、房、饭、反 |
| 前后鼻音 | `qian` | 枪、墙、前、钱、千 |
| 平翘舌 | `zi` | 知、之、子、字、自 |

关闭对应组后只剩精确读音：`la` → 啦/拉，`fan` → 饭/反，`qian` → 前/钱。

## 配置

配置文件键为 `fuzzy_groups`（数组），空数组表示精确拼音：

```json
{
  "fuzzy_groups": ["zh_z", "n_l", "r", "hu_f", "nose"]
}
```

各键含义：`zh_z` 平翘舌、`n_l` n/l、`r` r 系、`hu_f` h/f、`nose` 前后鼻音。旧配置 `fuzzy_pinyin`（`true`/`false`）仍兼容读取。

## 实现说明

全开或全关使用现成 schema；部分开启时按选中组动态合成一份 schema（首次切换时部署约 1 秒），之后即时生效。
